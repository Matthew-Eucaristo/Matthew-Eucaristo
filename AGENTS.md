# GitHub profile README

`README.md` renders on github.com/Matthew-Eucaristo. Terminal style: `$ command` headings, few sections (details live in `<details>`), no emoji walls, badge grids, stat cards, typing SVGs or invented numbers. Every claim and description comes from the real repo.

- `assets/header-{dark,light}.svg`: hand-written header, switched with `<picture>`.
- `graph/graph.json` + `graph/build.py` (stdlib Python) → `assets/graph-{dark,light}.svg` and `docs/graph.json`. The script picks the layout seed with the fewest edge crossings, drops every node the GitHub API does not report as public and adds tap edges from `homebrew-tap`. Never put a private or unreleased repo's name in `graph.json`. `.github/workflows/profile.yml` reruns it and `cards/build.py` on push to `graph/**` or `cards/**` and weekly, and commits only when output changes.
- `cards/cards.json` + `cards/build.py` (imports the palette and API helper from `graph/build.py`) → `assets/spotlight-*.svg` (cross-fading project slides, each with a small animated sketch) and `assets/shipped-*.svg` (latest releases of public repos). Pure SVG + CSS/SMIL so it animates in a README; honour `prefers-reduced-motion`. The first frame must be complete without animation (some viewers, such as the GitHub mobile app, never play it): nothing important may start at opacity 0; the spotlight uses negative delays so slide 0 is visible at t=0. Spotlight copy comes from each project's real README. Check a slide by opening the SVG and seeking `document.getAnimations()` + `setCurrentTime()`; headless `--virtual-time-budget` screenshots are unreliable for this.
- `docs/index.html`: interactive graph, served by GitHub Pages from `main /docs` at matthew-eucaristo.github.io/Matthew-Eucaristo (vanilla JS, reads `docs/graph.json`).
- `demo/tour.tape` + `demo/tour.sh` → `assets/tour.gif`. Render locally with `vhs demo/tour.tape` from the repo root, with the tool repos in `../dev-tools/`. Each tool builds from its public `origin/main` and runs in a child shell set up by its own `demo/setup.sh` (synthetic HOME, dummy data); never record the real machine. Then shrink the palette: `ffmpeg -i assets/tour.gif -vf "split[a][b];[a]palettegen=max_colors=96:stats_mode=diff[p];[b][p]paletteuse=dither=none:diff_mode=rectangle" /tmp/t.gif && mv /tmp/t.gif assets/tour.gif`. Keep the GIF under 1 MB.
- No PII beyond what the profile already shows. Commit with the GitHub noreply identity. Ask before pushing or enabling Pages.
